# Windows + VS Code Setup Template

This architecture pack is not executable code. When implementation is generated, use the repository README for exact commands.

Recommended prerequisites:
- Git for Windows
- VS Code
- Python 3.12+
- Node.js LTS
- Android Studio + Android SDK (for emulator/device builds)
- Expo account / EAS CLI for cloud Android builds
- MongoDB Atlas account and dedicated database user

PowerShell should be used for documented commands. Keep `.env` local and untracked. Never paste Atlas URI or admin password into source files, chat, screenshots, or frontend environment variables.
